🍕 Pizza Sales Report – Power BI Dashboard
📌 Project Overview
This project analyzes pizza sales data using Power BI to monitor key performance indicators (KPIs) and generate actionable business insights. The interactive dashboard helps track sales performance, identify trends, and evaluate product performance to support data-driven decision-making.

📊 Key Performance Indicators (KPIs)
1.Total Revenue
2.Total Orders
3.Total Pizzas Sold
4.Average Order Value (AOV)
5.Average Pizzas per Order

📈 Dashboard Features
1.Revenue and order trends (daily & monthly)
2.Sales analysis by pizza category and size
3.Top 5 Best-Selling Pizzas (Top Sellers)
4.Bottom 5 Lowest-Selling Pizzas (Bottom Sellers)
5.Peak sales days and months identification
6. Interactive filters and slicers for dynamic exploration

🛠 Tools & Technologies Used
1.Power BI
2.DAX (Data Analysis Expressions)
3.Power Query (ETL & Data Cleaning)
4.SQL (for data extraction and transformation)
